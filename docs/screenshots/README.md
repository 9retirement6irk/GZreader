# GZreader screenshots

<sub>Taken on GZreader's Kindle 3 emulator (the Kindle's own software, 600 × 800,
16 grey levels) with a demo library: public-domain books, made-up audiobooks and
made-up albums by made-up artists (`tools/gzreader/emulator/catalog_shots.lua`,
with `demo/demo_grimmory.py` and `demo/demo_plex.py`); the phone page in a
phone-sized browser talking to the emulated Kindle.</sub>
