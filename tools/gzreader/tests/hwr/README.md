Ink Away's handwriting tests (github.com/EmirErtorer/ink-away.koplugin, MIT
License, (c) 2026 Emir Devlet Ertörer), as they are, run against GZreader's
copies of its reader (gzreader_hwr.lua, gzreader_hwrnet.lua,
gzreader_hwrwords.lua) by tools/gzreader/tests/run.sh: it lays them out as
Ink Away has them (ink/hwr.lua, ink/data/…, tests/…) in a scratch folder.

The pen strokes in hwr_writers.lua, hwr_vectors.lua and hwr_word_vectors.lua
come from the UJI Pen Characters database, version 2 (Prat, Castro, Llorens,
Marzal and Vilar, Universitat Jaume I, 2008; UCI Machine Learning Repository),
licensed under Creative Commons Attribution 4.0
(https://creativecommons.org/licenses/by/4.0/). See
plugins/gzreader.koplugin/data/handwriting/NOTICE.md.
