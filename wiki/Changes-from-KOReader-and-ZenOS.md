GZreader is a fork of [KOReader](https://github.com/koreader/koreader) (currently `v2026.07.1`) with [ZenOS](https://github.com/xZenLabs/zen-os) (currently `4.3.2`) as its interface. Most of what it adds is its own plugin, `gzreader.koplugin`; where it had to change KOReader or ZenOS, the changes are marked in the code and checked by a test (`tools/gzreader/tests/keeps.py`), so an upstream update can't drop them unnoticed. Upstream updates are merged with `tools/gzreader/upstream.sh`.

## Compared with KOReader

**Left out** ([What's in GZreader](Whats-in-GZreader)): all bundled plugins except Cover browser, Statistics and Auto suspend (KOReader's own progress sync, OPDS, news downloader, SSH, terminal and the rest); KOReader's OTA updater; the CJK fallback font; UI translations; the first-run quickstart document.

**Added:**

- **Grimmory**: library browser, background downloads, sync of position, bookmarks, highlights, notes, ratings and reading sessions through Grimmory's own API (not its KOReader-compatible endpoint), audiobooks. → [Grimmory library](Grimmory-Library), [Grimmory sync](Grimmory-Sync)
- **The setup page** served by the device, copying connections between devices, sync with a computer for Kindles without Wi‑Fi. → [Setup page and connections](Setup-Page-and-Connections), [Sync with a computer](Sync-with-a-Computer)
- **Notes (Memos), Calendar (links and CalDAV), Music (Plex)**, read aloud with the Kindle's own voice.
- **Updates from GitHub** (its own updater), debug reports (only if you choose) and diagnostics. → [Updates](Updates-and-Test-Builds), [Privacy and diagnostics](Privacy-and-Diagnostics)
- **The quick panel**, replacing KOReader's top and bottom menus and ZenOS's touch menu on every device. → [Using GZreader](Using-GZreader)
- An English dictionary.
- **One rotation for Home and books:** KOReader's "Keep current rotation across views" is ticked once, so going Home from a book read sideways keeps the screen sideways (KOReader turned Home back to its own rotation, portrait). It can be unticked in Settings → Privacy and diagnostics → Advanced → KOReader settings → Screen → Rotation. → [Using GZreader](Using-GZreader#turning-the-screen)

**Changed in KOReader's own code:**

| Where | What |
| --- | --- |
| Kindle 2, DX, 3, 4 drawing (`frontend/device/kindle/shadowfb.lua`, `device.lua`) | A shadow screen: KOReader draws with its fast C blitter into an 8-bit buffer that's packed into the 4-bit (or inverted 8-bit) framebuffer before each refresh; night mode is done while packing. → [Performance](Performance) |
| Kindle start script (`platform/kindle/koreader.sh`) | Restarts, stepping aside for the Kindle's USB drive and coming back after it ("Connect to computer"), the Kindle 2/DX's framework for USB drive mode |
| Nook devices (`frontend/device/nook/`) | The Nook 1st Edition's e-ink page (refreshed through the kernel without a flash) and colour touchscreen (controls, reading info, a keyboard), the Simple Touch's e-ink waveforms and touch; the Nook start script and launcher (`platform/nook/`). → [Nook 1st Edition](Nook-1st-Edition) |
| Loading (`frontend/gzbytecode.lua`, `luasettings.lua`) | A bytecode cache for source installs; settings files are only written when they changed |
| Settings and book sidecars (`frontend/gzdataload.lua`, `luasettings.lua`, `docsettings.lua`, `luadefaults.lua`, `readhistory.lua`) | Read as data instead of run with `dofile`: a settings file, a book's `.sdr/metadata.*.lua` next to the book or a ZenOS quotes file can only give back its table (no commands, files or libraries; a file that loops is stopped). What KOReader writes reads the same. A translation's plural rule (`gettext.lua`, built from its `.mo` file) runs with nothing but the number in reach |
| Fonts (`frontend/ui/font.lua`) | Missing fallback fonts (the removed CJK one) are dropped at start instead of failing on every glyph |
| Book layout (`frontend/document/credocument.lua`) | A bigger crengine cache (256 MB instead of 64) |
| Sleep screen (`frontend/ui/screensaver.lua`) | GZreader's own sleep screen: the book's cover while reading and a picture elsewhere, whatever sleep screen was saved before (`frontend/gzsleepmode.lua`); "Custom image or cover" shows the book's cover while reading and the image elsewhere; Scale cover to fill screen (proportions kept, edges cut off; `frontend/gzsleepfit.lua`); with an Immich album chosen, a picture comes from its pictures first, then the folders (`gzsleepmode.pictureDirs`) |
| Menus (`frontend/ui/widget/touchmenu.lua`, menu orders) | Letter keys in KOReader's menus; GZreader's items in place of removed plugins' |
| Sizes on big screens (`frontend/gzuiscale.lua`, called from `reader.lua`) | On a screen over 5 inches across (the Scribe, the DX), menus, buttons and text are sized for the screen's density and grow only a little with its size, instead of with its width in pixels (a Scribe: 2.31 instead of 3.10). A book's font size and margins keep KOReader's sizes, and a DPI set in KOReader's Screen menu still wins |
| Home folder (`frontend/apps/filemanager/`) | No Home folder settings (Set, Shorten, Lock) in the file manager's menu and no "Set as HOME folder" buttons: the home folder is always the GZreader folder |
| Back key (`readerback.lua`), translations (`gettext.lua`), plugin loading | Small fixes for the trimmed build |

## Compared with ZenOS

GZreader keeps ZenOS's Home, tabs, library views, settings and setup guide, and changes:

- **Keys:** letter keys in every list and dialog (`__ZEN_DIALOG_SHORTCUTS`, the context menu), tab keys (Z, X, C, V, B) on keyboard Kindles, the 5-way on the Kindle 4. ZenOS was made for touch.
- **The quick panel** instead of ZenOS's touch menu (its Zen Mode button and tabs), on every device; ZenOS's first-run menu tour is replaced by one of the quick panel, which closes it before the page browser tip.
- **Home:** a bookshelf view (books on shelves, audiobooks as a cassette walkman, music as a CD player), Grimmory reading stats on a notebook page in place of ZenOS's local reading stats widget (no longer offered), two shelves on the DX's taller screen and the Scribe's bigger one; font sizes in Home widgets and the end-of-book page aren't scaled twice.
- **Tabs:** Catalog (Grimmory's books and audiobooks and Plex music, a page each; the Grimmory tab before 1.27.x), Notes (in Favorites' place) and Calendar, Music and Audiobooks on request.
- **The book menu:** Add to shelf and Remove from shelf (your Grimmory shelves, kept on the Kindle, changes sent over Wi‑Fi or by the sync page) instead of Add to collection, also for several selected books; no Add to collection anywhere.
- **The setup guide:** shorter (fewer pages, GZreader's reading defaults set on a first setup), starting with *How will you use GZreader?* (Grimmory, BookOrbit, or on its own) and *Set up from your browser*, ending with whether to send debug reports.
- **Settings → Home and tabs → Quick panel:** which tiles the quick panel shows, in place of ZenOS's Controls and Launcher (they set up the touch menu GZreader replaces).
- **Zen mode is always on** (ZenOS's own tabs only): there's no Zen mode switch in Settings → Interface, and it's turned back on if it was off.
- **The update screen:** GZreader's version and what's new in it, after every GZreader update (ZenOS showed its own version and list, only when ZenOS changed).
- **Settings, arranged as on an iPhone or a Mac:** the first page (nine rows at most, so it fits on one screen) is **Wi‑Fi** (On, Off or Auto in place of ZenOS's switch), then **General** (About, Software update, Storage, Battery, Time and date, Language, Transfer, Setup Guide, Performance), **Display and light** (Screen with the flash settings, Brightness and warmth, **Dark mode**, menu font, accent colour, icons), **Sleep and wallpaper**, **Audio** (Bluetooth first), **Home and tabs** (Home, Status bar, Tab bar, Quick panel, Downloads tab), **Reader**, **Accounts and services** (Books with your Grimmory account, Audiobooks, Music, Notes, Calendar, Photos, House) and **Privacy and diagnostics** (the diagnostic log, Report a problem, Advanced). ZenOS's Interface, Library (Downloads) and Extras sections and GZreader's Connections section are spread over these; Downloads tab → Folders has no Home folder menu (the home folder is always the GZreader folder).
- **Covers:** pre-sized and cached on disk, made in a background process. → [Performance](Performance)
- **Not loaded:** ZenOS's own updater (GZreader's replaces it; a small stand-in answers ZenOS) and its Rakuyomi manga integration unless that plugin is installed. → [Performance](Performance)
- **Immich (Photos):** Settings → Accounts and services has Immich, and Settings → Sleep and wallpaper → Home background has **Picture from Immich** (a picture from your Immich album behind Home and the tabs, another one when new pictures come; `common/gz_immich_wallpaper.lua`). → [Home and bookshelves](Home-and-Bookshelves#pictures-from-immich)
- **The reader's top status bar** (Settings → Reader → Appearance → Top status bar: the clock, by default) stays on screen while the layout menu (the quick panel's Layout) is open and after it closes; ZenOS drew it only while nothing else was open over the book, so it went missing until the next page turn.
- **A tap on the bottom status bar hides it** after the setup guide (Hide on tap: Bottom). ZenOS's status bar presets lock the bar, so with its defaults that tap turned the page; the presets themselves are unchanged (`common/reader_defaults.lua`).
- **Wi‑Fi in the status bars** (Home's and a book's top bar): an **A** after the Wi‑Fi icon while Wi‑Fi is on Auto (`common/gz_wifi_icon.lua`); the icon itself still shows on or off.
- **Settings, rearranged:** every row has an icon. General has Time and date (Time zone first), Language and Storage (what's on the Kindle: each part with its size, and an arrow into the biggest of each), which were in About → Device or at the top of Settings. Sleep → Wallpaper shows the sleep screens as tiles with previews, its other settings under Wallpaper options; no custom image, no sleep-screen presets. General comes first in Settings. General → Screen is KOReader's Screen menu (moved there from KOReader's settings), and its E-ink settings hold every setting about when the screen flashes: KOReader's Full refresh rate, then GZreader's Flash on every page turn, Flash when the screen changes and Partial pages refresh (they were in Reader → Appearance and Advanced, then General → Screen refresh). ZenOS's Flash on every CBZ page turn is gone: KOReader's Always flash on pages with images covers comics.
- **Fewer settings that don't apply:** Settings → General → About starts with GZreader's version ("Built on ZenOS … and KOReader …" under it); **Report a problem** (Settings → Privacy and diagnostics, in place of ZenOS's Report a bug) sends to GZreader's developer, not ZenOS's issue tracker. Settings → Privacy and diagnostics → Advanced holds KOReader settings (KOReader's whole menu), and no Debug logging, Clear all gestures, Plugin management, Patch management, Extract metadata, Show hidden files or Allow dragging reader modals (a saved tick of the last two is turned off once). Where GZreader shows KOReader's rows outside About → Advanced → KOReader settings (General → Screen, the KOReader menu a bottom swipe can open), it leaves out the File browser menu (Downloads' own Sort and Filter set the same things), no Tools → Reading statistics (the statistics are still kept), and no Plugin management, Patch management, Developer options, file browser Display mode or Start with, Wi‑Fi actions, Restore Wi‑Fi or Disable Wi‑Fi connection when inactive, second Grimmory menu, Disable double tap (GZreader has no double-tap actions; a saved untick is cleared once), Book metadata location and Move book metadata (GZreader looks for a book's metadata next to it), or Help → Report a bug and Disable external plugins (GZreader's own plugins count as external). No Manga, News or Calibre Search tabs.
- **Kobos:** GZreader replaces KOReader in `.adds/koreader`, with NickelMenu and KFMon entries named GZreader; KOReader's start script says GZreader and an update brings it; messages say "Kobo"; Connect to computer uses KOReader's own USB mode; sign-ins kept in `/usr/local/gzreader`, off the USB drive. → [Kobo](Kobo)
- **Nooks:** paths for a Nook's microSD card, no Bluetooth, Wi‑Fi switching adapted.
- **Bluetooth** (Settings → Audio → Bluetooth, ZenOS's device list) only on Kindles that have it: GZreader asks Amazon's Bluetooth service once at start (`common/gz_bluetooth.lua`), so the Kindle 3 and other Kindles without it never run a Bluetooth check; only ZenOS's Kindle adapter is included. → [Bluetooth](Bluetooth)
- **Settings → Reader in six rows:** Gestures and controls (Bottom swipe gesture, Reader controls, Page Browser) and Notes and footnotes (Annotation viewer, Footnotes and pinned pages) are submenus; ZenOS has the five side by side. The Settings buttons in the page browser, the annotation viewer and the footnotes drawer open their page inside the group.
- **No Extras section in Settings:** its Schedules and Sleep are in General and Custom icons in Interface (as in ZenOS); the rest (Stats tab widgets, ZenPM, Rakuyomi, Zen Search, Lockdown mode, Zen Keyboard) isn't offered, and keeps its default or what was set before.
- **GZreader's menus look like ZenOS's Settings:** the Calendar and Notes tabs' connect lists, Plex's sign-in and the Music list, Downloads, the sync queue, copying from another GZreader, the Notes filters, the font list and Add to shelf have ZenOS's rows: an icon on the left, an arrow on the right of each row that does something, ZenOS's spacing, and short labels (longer explanations behind an **About …** row). Lists of books, albums and tracks keep their own look.
- **No Metadata menu in Settings → Home and tabs → Downloads tab → Books** (ZenOS's online sources for its metadata editor): a download's title, authors and series come from Grimmory. **Square cover corners in the Bookshelf view** (Rounded cover corners is greyed out there; the other views keep their setting).
- **No Double tap on the Kindle 2, 3, DX and 4** (Settings → Home and tabs → Downloads tab → Books; ZenOS's Double-tap to open a book before 4.3.2): they open books with keys or the 5-way, so there's nothing to tap. The touch Kindles still have it, with Single tap and Double tap under it (what each does to a book: open it, its menu, or nothing).
- **Branding:** GZreader's name and logo; a "GZreader" item on the touch Kindles' home screen instead of ZenOS's.
- **No KOReader section in Settings:** KOReader's whole menu, nothing left out, is **Settings → Privacy and diagnostics → Advanced → KOReader settings** (for whatever is open: Home or the book). What GZreader has elsewhere is there too: Language, Time and date, Sleep screen, Autosuspend timeout, Wi‑Fi connection, HTTP proxy and Network info (Settings → General, the last three in Wi‑Fi), History, Favorites and Collections (tabs), End of document action (Reader → End of book), Night mode, Rotation and Exit (quick panel tiles), Activate menu (Interface → Quick panel), the Screen menu (Settings → Display and light → Screen), Version, About and Quickstart guide (Settings → General → About, Setup Guide).

The full list of changed upstream files is `tools/gzreader/tests/keeps.txt` in the repository.
